### Detalle (medio/alto/crítico)

#### A-001 — CI roto (Symfony 8.1 / PHP 8.4)

- **Evidencia:** `gh run view 28895273158 --log-failed` → `symfony/http-foundation v8.1.1 requires php >=8.4.1 -> your php version (8.3.32) does not satisfy that requirement.` Laravel `v13.17.0` locked.
- **Impacto:** Ningún commit en `main` pasa tests/build/scribe en CI. Regresiones no detectadas automáticamente.
- **Recomendación humana:** Opción A — `php-version: '8.4'` en `.github/workflows/tests.yml`. Opción B — `composer update` con constraint Symfony `^7.4` si VPS sigue en 8.3.

#### A-002 — Webhooks Green API incompatibles

- **Evidencia:**
  - `ProvisionGreenInstanceJob` línea 70: `'webhookUrlToken' => config('services.green_api.webhook_secret')`
  - `VerifyWebhookSignature`: valida `X-Webhook-Signature` HMAC SHA-256
  - Tests (`WebhookVerificationTest.php`) solo cubren HMAC, no el mecanismo Green API
  - Spec `2026-06-29-green-api-partner-instances-design.md` confirma `webhookUrlToken`
- **Impacto:** Instancias provisionadas no recibirán actualizaciones de estado vía webhook; sync manual o polling requerido. Bloquea E2E paso 2 (QR → authorized).
- **Recomendación humana:** Implementar validación dual: Bearer token / query param `token` + mantener HMAC opcional para futuro. Actualizar contrato y tests.

#### A-003 — Migración commercial fields pendiente VPS

- **Evidencia:** Migración añade columnas aditivas con defaults (`commercial_status` default `demo`). Último migrate VPS documentado en checklist G0.1: `int_mensajes` (2026-07-02).
- **Impacto:** `POST /account/status` y cuotas mensuales fallarán o devolverán datos incompletos si columnas no existen.
- **Recomendación humana:** `php artisan migrate` en VPS + `scripts/vps-sync-platform-perms.sh` para permiso `cuenta.ver`.

#### A-005 — int_webhooks sin persistencia

- **Evidencia:** Migración `2026_07_02_100001_create_int_webhooks_table.php` crea tabla; `IncomingWebhookController` solo actualiza `Instancia` en `stateInstanceChanged`, no inserta en `int_webhooks`. Test en `MessageSendTest.php` solo verifica existencia de tabla.
- **Impacto:** Sin trazabilidad de eventos webhook; idempotencia depende de Cache Redis (TTL 24h).
- **Recomendación humana:** Persistir payload en `int_webhooks` antes de procesar; usar DB como fuente de idempotencia.
