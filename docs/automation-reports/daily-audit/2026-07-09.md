### Detalle (medio/alto/crítico)

#### A-001 — CI roto (Symfony 8.1 vs PHP 8.3)

- **Evidencia:** Run `28895273158` (push `ab6c83a` a `main`, 2026-07-07): 19 conflictos de `composer install`; ej. `symfony/http-foundation v8.1.1 requires php >=8.4.1 -> your php version (8.3.32)`.
- **Impacto:** Ningún PR puede validarse en CI; regresiones no detectadas automáticamente.
- **Recomendación humana:** Opción A — `php-version: '8.4'` en workflow + verificar VPS PHP; Opción B — `composer update` pinneando Symfony 7.4.x compatible con PHP 8.3.

#### A-002 — Webhooks Green API incompatibles

- **Evidencia:**
  - `ProvisionGreenInstanceJob` línea 70: `'webhookUrlToken' => config('services.green_api.webhook_secret')`
  - `VerifyWebhookSignature`: exige header `X-Webhook-Signature` (HMAC SHA-256 del body)
  - `WebhookIdempotency`: exige header `X-Event-Id`
  - Spec Green API (`2026-06-29-green-api-partner-instances-design.md`): token vía `webhookUrlToken`, no HMAC custom
  - Tests (`WebhookVerificationTest.php`) validan el esquema HMAC custom, no el protocolo Green API real
- **Impacto:** `stateInstanceChanged` y mensajes entrantes no actualizarían instancias en producción; smoke paso 2 (QR/autorización) podría depender de polling manual.
- **Recomendación humana:** Implementar middleware dual: validar `Authorization: Bearer {WEBHOOK_SECRET}` para Green API; mantener HMAC como opción futura para webhooks propios. Generar `X-Event-Id` sintético desde hash del payload si Green API no lo envía.

#### A-003 — Migración commercial fields

- **Evidencia:** Migración aditiva con `down()` seguro; documentada en deploy G0.1 pero commit `0e2302a` posterior al evidence gate.
- **Impacto:** Columnas faltantes → error SQL en endpoints que lean `commercial_status`, `demo_expires_at`, `messages_monthly_limit`.
- **Recomendación humana:** En VPS: `php artisan migrate:status` y ejecutar migrate si pendiente.

#### A-005 — int_webhooks sin uso

- **Evidencia:** Migración `2026_07_02_100001_create_int_webhooks_table.php`; único uso en test de schema (`MessageSendTest.php`); controller no inserta filas.
- **Impacto:** Pérdida de auditoría de eventos webhook; idempotencia volátil si Redis se vacía.
- **Recomendación humana:** Implementar persistencia según plan `2026-07-02-integration-phase4-5.md` § WebhookEvent.
