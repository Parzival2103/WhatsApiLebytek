#### A-001 — Deploy VPS pendiente PR #29

- **Evidencia:** Merge `9e62475` (2026-07-18). Cambios: `ProcessWebhookJob`, `IncomingWebhookController` persist-then-dispatch, supervisor `webhooks` en `config/horizon.php`, `Schedule::command('webhooks:check-unprocessed')` en `routes/console.php`. `docs/DEPLOY.md` documenta cron `schedule:run` requerido.
- **Impacto:** Sin deploy, webhooks entrantes no se persisten ni procesan de forma fiable; instancias pueden quedar desincronizadas tras QR/logout.

#### A-002 — PATCH tenants bypass activate-plan (Issue #21)

- **Evidencia:**

```19:28:app/Http/Requests/Api/V1/UpdateTenantRequest.php
        return [
            'name' => ['sometimes', 'string', 'max:255'],
            'isActive' => ['sometimes', 'boolean'],
            'commercialStatus' => ['sometimes', 'string', 'in:demo,active,past_due,cancelled'],
            'planSlug' => ['sometimes', 'string', 'max:50'],
            // ...
        ];
```

`ActivatePlanService` es el único flujo con rotación de token y escritura en `meta.activation`.

- **Impacto:** Inconsistencia límites plan-aware vs abilities del token; bypass de billing.
- **Recomendación humana:** Restringir PATCH a `name`/`isActive` o rechazar campos comerciales con 422.

#### A-003 — Webhook sin throttle

- **Evidencia:** Grupo API v1 usa `throttle:api`; webhooks usan solo `webhook.signature`:

```95:97:routes/api.php
Route::prefix('v1/webhooks')->middleware(['webhook.signature'])->group(function (): void {
    Route::post('/incoming', IncomingWebhookController::class)->name('api.v1.webhooks.incoming');
});
```

- **Impacto:** Sin límite de tasa a nivel HTTP; depende 100 % de firma válida.
- **Recomendación humana:** Añadir `throttle:webhooks` en `bootstrap/app.php` / `RouteServiceProvider` con límite generoso (p. ej. 120/min por IP).
